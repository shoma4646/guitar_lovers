# 再設計ブリーフ: スクロールさせない1画面レイアウト（2026-09-20）

`/design` でモックアップを作るときの前提。現行実装のトークンと画面構成、守るべき制約をまとめる。

## プロダクト

YouTube動画の区間を「フレーズ」として保存し、BPMを少しずつ上げながら反復練習するギター練習アプリ（iOS、縦画面のみ）。コアループは「区間を見つける → フレーズ保存 → 翌日ワンタップで再開 → BPMを上げる → 記録 → 卒業」。詳細は `docs/product-definition.md`。

## 制約

- **縦スクロールをさせない**。各タブは iPhone 15 Pro / 16 Pro（393 x 852pt / 402 x 874pt、セーフエリア込み。狭い方の393 x 852を基準に積む）の1画面に収める。情報が多い部分はタブ内の切り替え、折りたたみ、シート（下から出るモーダル）で逃がす
- タブは Practice / Progress / Tuner の3つ（下部タブバー）。設定はヘッダーの歯車からモーダル
- 既存トークン（下記）と Material 3 風の階層は維持する。ライトテーマのみ
- 絵文字は使わない。日本語UI

## 現行の画面構成と、スクロールが発生している理由

### Practice（主役）

上から順に縦に並び、明らかに1画面に収まらない。

1. 今日の練習メニュー（TodayMenuCard）: 先頭が「今日の1本」（理由付き強調）、以降はフレーズ一覧（前回BPM → 今日の目標BPM、卒業は末尾に「卒業・」）。長押しでアーカイブ/削除
2. 練習中バー（ActivePracticeBar、画面下固定）: 「BPM 92で3回」「+1回」「終了して記録」
3. 動画URL入力（VideoLoaderCard）
4. 動画プレイヤー（VideoPlayerCard、16:9のWebView、最小高200）
5. 練習タイマー（PracticeTimerCard）
6. 再生速度チップ（0.5〜1.0）
7. ABループ（A点/B点の設定、ループON/OFF、フレーズとして保存）
8. ブックマーク一覧
9. メトロノーム（BPM、ON/OFF）

タブ内サブタブ: 練習 / プリセット / お気に入り。

設計のヒント: 「今日の1本 → 弾く → 記録」が主動線。動画と、その直下にABループ・BPM（メトロノーム）・再生速度を1つの操作パネルにまとめ、URL入力・ブックマーク・タイマーは補助としてシートやアイコンに逃がす。メニュー一覧は動画を読み込む前だけ広く見せ、練習中は「今日の1本」だけに縮める、など。

### Progress

1. フレーズの上達（フレーズ別に 開始BPM → 現在BPM / 目標、進捗バー）
2. 卒業したフレーズ（一覧、卒業日）
3. 主指標カード: 今週の練習日数（大）、連続日数（小）
4. 今週の練習日（月〜日のバー、練習した日だけ塗る）
5. 最近のセッション一覧 + 追加FAB
6. ヘッダーにシェア

設計のヒント: 主指標と週のバーを上部にコンパクトに、フレーズ一覧と卒業一覧はセグメント切り替え、セッション一覧はシートへ。

### Tuner

1. 大きな正方形カード: Hz、マイク入力レベル（dB）、中央に音名（弦名 / プリセット外は実音名 / 未検出は --）、針メーター（±50 cents）、cents表示
2. 6弦のボタン（チューニング済みは緑）
3. プリセット切替（Standard / Half step down / Drop D）
4. 開始/停止ボタン

ここはほぼ1画面に収まっている。メーターと弦ボタンの視認性向上が主題。

### 設定（モーダル）

アプリについて / プライバシーとサポート / 練習リマインド（ON/OFF、送信時刻の±30分、次回表示）/ 利用しているサービス。

## スクリーンショットから見える課題（2026-09-20時点）

- Practice: ヘッダー（アプリ名・タグライン・「Practice Dashboard」見出し・サブタブ）だけで画面の約4分の1を使っている。練習タイマーのカードも大きく、動画プレイヤーが初期表示に入らない
- Progress: 「今週の練習日数 0/7日」の下に THIS WEEK / HOURS / SESSIONS の3カードが並び、単位が「0秒」表記。主指標と補助指標の階層が弱く、週のバーの上に空白が大きい
- Tuner: 未検出時の音名「--」がディスプレイ用の太字で赤い2本の棒に見える。プリセットのボタンが3つで2段に折り返し、開始ボタンがタブバー直上でかろうじて見えている。6弦のラベルが「e2」と小文字で表示されている（要確認）
